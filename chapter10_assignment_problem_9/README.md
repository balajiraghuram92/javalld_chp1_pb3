Filter and Double Even Numbers (Assignment):
===========================================

Problem Statement:
-----------------   
Implement a function filter_and_double_even_numbers that takes a list of integers as input. It should filter out the even numbers from the input list, double each of them, and return a list containing the doubled values.

Task Description:
-----------------

In Java, this pipeline is implemented using Streams: .filter() to select even numbers, .map() to double them, and .collect() to return the final list. 
 
Description:
------------

Implement a method filterAndDoubleEvenNumbers(List<Integer> numbers) that receives a list of integers as input and returns a new list containing doubled values of only the even integers, preserving their original order.
