Problem Statement: Concurrent Counter Management (Java Version)

You are tasked with implementing a thread-safe Counter class in Java to handle concurrent increment and decrement operations across multiple threads.



Requirements (Counter Class)

Constructor (Counter(int initialCount)): Initializes the counter with the specified initial count.



incValue(int offset): Safely increments the counter value by the specified offset.



decValue(int offset): Safely decrements the counter value by the specified offset.



getValue(): Safely retrieves the current value of the counter.
