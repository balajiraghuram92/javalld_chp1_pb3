Generic Linked List Implementation:
==================================
Problem Statement:
------------------

You are tasked with implementing a generic linked list data structure in Python. The linked list should be able to store elements of any type and provide methods for appending new elements and printing the list.

Requirements:
-----------------
In Java, strong compile-time generics (<T>) replace Python's TypeVar and Generic[T].Task DescriptionImplement a generic singly linked list capable of holding elements of any reference type (Integer, String, etc.).
Maintain $O(1)$ append performance by maintaining both head and tail references.
