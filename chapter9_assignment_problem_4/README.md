Generic Pair Class Challenge:
============================

Problem Statement:
-----------------
You are tasked with implementing a generic Pair<T, U> class in Java that accepts two type parameters, T and U, representing the types of the first and second elements of the pair, respectively.

Requirements :
------------
Generic Class Structure: Define a class Pair<T, U> that can hold two fields of generic types T and U.

1. Constructor: Implement a constructor Pair(T first, U second) that initializes the pair with the specified elements.

2. Accessors: Provide getter methods (getFirst(), getSecond()) to retrieve the elements.

3. String Representation: Override the standard toString() method to customize the string representation of the pair, matching the format Pair(first, second) (e.g., Pair(1, apple)).

4. Usage Demonstration: Demonstrate the functionality of the Pair class by creating instances with various type combinations (such as integers, strings, lists, and maps).
